# Ultra Modern Developer Portfolio Landing Page

Eti ekdom premium, glassmorphism UI, glowing ambient mesh effects, ebong dynamic typing animation shoho toiri kora ekta sleek developer portfolio template.

## File List:
- `index.html`: Modern semantic HTML structure
- `style.css`: Ultra-clean glassmorphic UI + glowing effects
- `script.js`: Dynamic typing text, smooth scroll & form notification
- `avatar.png`: Ekhane apnar chobi avatar.png name save kore rakhun

## Kivabe setup korben:
1. `index.html` file ti text editor (VS Code) diye open kore 'Your Name', 'Skills', 'Projects' ebong Contact info update kore nin.
2. Apnar profile chobi ti 'avatar.png' name ei folder e replace korun.
3. GitHub e ekta notun Public repository toiri korun.
4. Shobgulo file drag & drop kore GitHub e commit korun.
5. Repository Settings -> Pages e giye Branch 'main' select kore Save din.
6. 1-2 min por GitHub Pages e apnar site live hoye jabe!
